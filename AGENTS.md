# Der Wegweiser — Autonomous Agents Architecture

- **Identifier**: `wegweiser-implementer`
- **Scope**: Frontend components, routing algorithms, BLE telemetry parsers, and Firebase services.

## 3. Vertex AI Cloud Agent
- **GCP Project**: `der-wegweiser`
- **Location**: `europe-west3`
- **Scope**: Heavy background routing computation, topography simulation, OpenStreetMap charging station verification.
